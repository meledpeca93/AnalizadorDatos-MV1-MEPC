Las claves para entender sus resultados

Un pequeño mapa de lo que ocurre dentro de la computadora.

01 / Una base es una forma de contar

La base indica cuántos dígitos se usan. Binario usa 0 y 1; decimal, del 0 al 9. En hexadecimal, A–F representan los valores 10–15.

02 / Los bits se agrupan en bytes

Un bit vale 0 o 1. Un byte reúne 8 bits. El número 5 es 101 en binario; se completa como 00000101 para ocupar un byte.

03 / Unicode identifica; UTF-8 codifica

Unicode asigna un código a cada carácter. UTF-8 lo convierte en una secuencia de 1 a 4 bytes. Por eso la longitud del texto y su tamaño en bytes pueden diferir.

¿Qué significan decimal, punto U+ y hexadecimal en la tabla?

Son formas de mostrar el mismo identificador Unicode. Para ñ: decimal 241, punto de código U+00F1 y hexadecimal F1. La columna UTF-8 muestra su codificación en memoria: C3 B1. No confunda el identificador con los bytes que lo almacenan.

¿Por qué algunos símbolos cuentan como varios caracteres?

Este analizador cuenta puntos de código, no símbolos visuales (grafemas). Por ejemplo, una letra seguida de una tilde combinada contiene dos puntos de código aunque se vea como una sola letra. Algunos emojis también combinan varios. El límite de entrada es de 20 puntos de código.

¿Cómo se relaciona esto con la computadora y Docker?

La CPU ejecuta las conversiones y la RAM guarda los datos de trabajo. El navegador envía las entradas y recibe los resultados. Docker permite ejecutar la misma aplicación y sus dependencias en un entorno reproducible, compartiendo el kernel del host Linux del contenedor. En Docker Desktop, ese kernel pertenece a su máquina virtual Linux.
